# SDR
## Описание проекта 
Программный модуль для генерации, передачи, приёма и демодуляции цифровых сигналов с использованием SDR-платформы **ADALM-PLUTO**. Проект реализует полный цикл обработки на физическом уровне: от формирования символов до восстановления данных, включая алгоритмы частотной и временной синхронизации. Визуализация сигналов, спектров и созвездий выполняется в реальном времени с помощью **Dear ImGui + ImPlot**.


## Реализованный функционал

| Модуль | Описание |
|--------|----------|
| **Модуляция/Демодуляция** | Поддержка схем **BPSK, QPSK, QAM16**. Побитовое маппирование/демаппирование, генерация тестовой последовательности (PRBS), мягкие/жёсткие решения при декодировании |
| **Частотная синхронизация** | Коррекция смещения несущей (CFO) алгоритмом **Costas Loop** с фазовым детектором. Компенсация расхождения гетеродинов TX/RX и доплеровского сдвига |
| **Временная синхронизация** | Обнаружение начала кадра по корреляции с преамбулой |
| **Визуализация (Dear ImGui)** | Интерактивный GUI с вкладками: **созвездие** |
| **Интеграция с ADALM-PLUTO** | Прямая работа с устройством через `libiio`, настройка частоты, усиления, частоты дискретизации, управление буферами TX/RX |

## Структура проекта
```
---/
├── build/                      # Директория для сборки (генерируется CMake)
│
├── include/                    # Заголовочные файлы и интерфейсы
│   ├── imgui.h                # Подключение графического интерфейса Dear ImGui
│   ├── implot.h               # Подключение библиотеки визуализации ImPlot
│   ├── mapper.cpp             # Реализация модулятора/демаппера (BPSK/QPSK/QAM16)
│   └── mapper.h               # Заголовочный файл mapper
│
├── src/                       # Исходный код приложения
│   ├── analiz.py              # Python-скрипт для анализа результатов 
│   └── main.cpp               # Точка входа, основной цикл обработки сигналов
│
└── third_party/               # Внешние зависимости (субмодули)
    ├── imgui/                 # Библиотека Dear ImGui (GUI)
    └── implot/                # Библиотека ImPlot (визуализация графиков)
```
## Сборка
```
mkdir build & cd build
cmake ..
make
```
## Запуск
```
./main
```
