# SDR 

Программно-опредеялемая радиосистема (SDR) для работы с Adalm-Pluto (PlutoSDR) с возможность передачи и приема сигнала, а также визуализации IQ данных в реальном времени.

## О проекте

Этот репозиторий содержит реализацию алгоритмов обработки сигналов для Software Defined Radio (SDR):

- Синхронизация по частоте (Frequency Synchronization)
- Детектор фазовой ошибки (Timing Error Detector, TED) для BPSK 
- Модуляция/демодуляция цифровых сигналов

Проект написан на **C++** с использованием **Makefile** для сборки.
